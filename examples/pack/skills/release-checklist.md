# Release checklist

Fictional content, included to show the file shape.

1. The changelog entry exists and names the user-visible change.
2. A migration, if any, has been run against a copy of production data.
3. Someone other than the author has approved the merge request.
4. The tracker ticket is moved to *Ready to verify*, not *Done* — only the
   reporter closes a ticket.
